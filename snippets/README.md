# Snippets

Fragmentos del código de Datafaro, algunos recortados o simplificados para que se lean solos. No hay secretos, datos de clientes ni configuración real.

| Fichero | Qué muestra |
|---|---|
| [politica-autonomia.ts](politica-autonomia.ts) | La matriz de autonomía: qué se aplica solo y qué necesita aprobación, según el nivel de servicio. En una propuesta manda el cambio más restrictivo |
| [puerta-ia.ts](puerta-ia.ts) | Una sola puerta a la IA: presupuesto, contrato de salida con zod, un reintento y registro de coste |
| [guardia-de-destinos.ts](guardia-de-destinos.ts) | Protección contra SSRF: resolución DNS, rangos internos y redirecciones seguidas a mano |
| [rutas-ssh.ts](rutas-ssh.ts) | Qué fichero se puede tocar por SFTP: ruta resuelta, listas blanca y negra, y reemplazo con número de ocurrencias exacto |
| [puntuacion.ts](puntuacion.ts) | La nota de una auditoría: penalizaciones sobre el peso evaluado, escala por páginas afectadas y nota por categoría |
